# FACE NOTE
모바일 화면의 정적 웹 앱 기본 틀입니다. DB·분석 API·로그인 없이 동작합니다.

## 실행
프로젝트 face_score_web 폴더에서:
```
python serve.py
```
브라우저: http://localhost:8765
정적 파일을 제공하는 로컬 개발 서버일 뿐, 사진을 받거나 분석하는 백엔드는 없습니다.
HTML 파일을 직접 더블클릭하면 ES module과 카메라가 제한될 수 있으므로 위 방식으로 실행하세요.
모바일 배포는 frontend 폴더를 HTTPS 정적 호스팅에 올립니다. localhost는 접속 기기 자신을 의미하므로 PC localhost 주소를 휴대폰에서 그대로 열 수는 없습니다.

## 구현
- 최대 너비 440px, 모바일 반응형 레이아웃
- JPG/PNG/WebP 업로드, 10MB 및 20MP 제한, 미리보기
- 카메라 촬영/권한 오류/재촬영, 닫거나 화면을 떠나면 카메라 종료
- 선택 이미지 PNG 다운로드
- 한글 파일명 표시(textContent), 메모리 URL 정리
- 사진은 브라우저 메모리에서만 처리. DB/localStorage/업로드 API 없음.
- 폰트는 Google Fonts 요청을 사용하며 이미지 데이터는 전송하지 않습니다. 오프라인은 시스템 글꼴로 표시.
